# ESP32 Multisensory Alarm

An ESP32-based multisensory alarm system using light, vibration,
airflow, and configurable wake-up sequences.

## Features

- Gradual light intensity control
- Vibration motor control
- Fan-based airflow
- Configurable alarm timing and intensity
- ESP-NOW communication
- Blynk control
- LCD interface
